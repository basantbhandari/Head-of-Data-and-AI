# Top 30 most-used algorithms

One-line descriptions of 30 widely used ML algorithms, grouped by family.

## Supervised learning (classic)

- Linear Regression: predicts a number from a straight-line relationship (e.g., house price from size)
- Logistic Regression: predicts a yes/no outcome, used for classification (e.g., spam or not)
- Decision Tree: tree-like model of if-else rules, easy to visualize
- Random Forest: combines many decision trees, more accurate and less prone to overfitting
- Support Vector Machine (SVM): finds the best boundary that separates classes, good for high-dimensional data
- k-Nearest Neighbors (k-NN): compares a new point to its closest data points, with no learning phase
- Naive Bayes: based on Bayes’ Theorem, assumes independent features, good for text classification

## Boosting

8\. Gradient Boosting: builds models one after another, each fixing the previous one’s mistakes

9\. AdaBoost: combines weak models into a strong one using weighted votes

10\. XGBoost: a fast, efficient version of gradient boosting, very popular in competitions

## Unsupervised learning

11\. k-Means Clustering: groups data into k clusters based on similarity

12\. Hierarchical Clustering: builds a tree of clusters by merging or splitting groups

13\. DBSCAN (Density-Based Spatial Clustering): groups nearby points and marks isolated points as outliers

14\. Principal Component Analysis (PCA): reduces the number of features while keeping the most important information

15\. t-SNE (t-distributed Stochastic Neighbor Embedding): visualizes high-dimensional data in 2D or 3D

## Reinforcement learning

16\. Q-Learning: learns the best action to take in a situation to maximize reward

17\. SARSA (State-Action-Reward-State-Action): like Q-learning, but updates using the current action policy

18\. Deep Q-Network (DQN): combines Q-learning with deep learning for complex environments like video games

19\. Policy Gradient: directly learns the best actions by adjusting the policy using reward feedback

20\. Actor-Critic: combines policy gradient (actor) and value-based learning (critic) for more stable training

## Deep learning

21\. Artificial Neural Network (ANN): mimics how the brain works, using layers of neurons

22\. Convolutional Neural Network (CNN): for images, detects edges, patterns, and objects

23\. Recurrent Neural Network (RNN): for sequences like text or time series, remembers previous steps

24\. Long Short-Term Memory (LSTM): a type of RNN that handles long-term dependencies, great for text and speech

25\. Transformer: uses attention to understand sequences all at once, the base of models like GPT

## Other/specialized

26\. K-Means++: a smarter way to initialize cluster centers in k-means to improve accuracy

27\. Autoencoders: compress data, then reconstruct it; used for denoising and dimensionality reduction

28\. Isolation Forest: detects outliers or anomalies in data

29\. Markov Decision Process (MDP): mathematical framework for modeling decision-making, the foundation of reinforcement learning

30\. Genetic Algorithms: mimic natural evolution by selecting, combining, and mutating solutions
